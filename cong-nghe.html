04 · CÔNG NGHỆ

Từ file trống tới chạy thật

Nghề cũng là sở thích. Thích nhất là cảm giác gõ git push rồi vài chục giây sau mở trình duyệt thấy thứ mình vừa viết đang sống trên internet.

  • Web
  • DevOps
  • Linux
  • CI/CD
  • Tự động hoá
01

Thứ mình dùng hằng ngày

Phía người dùng nhìn thấy

  • HTML & CSS viết tay, không framework khi không cần
  • JavaScript thuần cho mấy thứ nhỏ
  • SVG cho hình minh hoạ — nhẹ và sắc ở mọi màn hình
  • Responsive từ đầu, không chắp vá sau

Phía sau

  • Linux (Ubuntu) trên VPS
  • Nginx phục vụ web tĩnh
  • SSH + key, không dùng mật khẩu
  • Git cho mọi thứ, kể cả file cấu hình

Tự động hoá

  • GitHub Actions chạy khi push lên nhánh chính
  • Secrets giữ khoá SSH, không nhét vào repo
  • Script nhỏ dọn log, backup định kỳ
  • Đặt lịch cron cho việc lặp lại
TRIẾT LÝ Chọn thứ đơn giản nhất mà vẫn giải quyết được việc. Một trang tĩnh và một con VPS 5 đô chạy ổn định hơn nhiều so với một mớ dịch vụ mình không hiểu hết.
02

Chuyện gì xảy ra sau khi push

Đường đi của một thay đổi

  • 1 · Commit ở máy Sửa file, xem thử ở trình duyệt, commit với một câu mô tả cho ra hồn.
  • 2 · Push lên nhánh main Đây là hành động duy nhất mình phải làm bằng tay. Phần còn lại máy lo.
  • 3 · GitHub Actions bật dậy Workflow lắng nghe sự kiện push, dựng một máy ảo sạch, checkout mã nguồn.
  • 4 · Kết nối VPS bằng khoá SSH Khoá riêng nằm trong Secrets của repo, không bao giờ xuất hiện trong log.
  • 5 · Copy file lên thư mục web Chép thẳng HTML, CSS và ảnh vào thư mục Nginx đang phục vụ.
  • 6 · Xong — không cần restart Web tĩnh nên không có tiến trình nào phải khởi động lại. Tải lại trang là thấy.

Vì sao không dùng thứ phức tạp hơn

Không Docker, không pm2, không build step. Trang này chỉ là HTML và CSS — thêm một lớp công cụ nào nữa cũng chỉ thêm chỗ để hỏng. Khi nào thật sự cần thì thêm sau.

03

Mấy thứ nghịch cho vui

🌐 Trang cá nhân này Viết tay từ đầu, không template. Vừa để khoe sở thích, vừa là bãi thử nghiệm CSS.
🤖 Script dọn dẹp Vài dòng shell chạy theo cron, dọn log và backup. Việc nhàm chán thì để máy làm.
🔧 Cấu hình Nginx Nghịch cache header, gzip và chứng chỉ HTTPS. Học được nhiều nhất từ mấy lần cấu hình sai.
📊 Theo dõi VPS Ngó RAM, ổ đĩa và uptime. Không phải vì cần, chỉ vì nhìn biểu đồ thấy vui.
🎨 Vẽ hình bằng SVG Toàn bộ minh hoạ trên trang này đều gõ tay bằng toạ độ. Chậm, nhưng nhẹ và tự do.
🔐 Siết bảo mật cơ bản Tắt đăng nhập mật khẩu, đổi cổng SSH, bật tường lửa. Làm một lần, yên tâm về sau.
04

Vài nguyên tắc tự rút ra

Giữ

  • Làm cho chạy trước, làm cho đẹp sau
  • Việc nào làm quá hai lần thì viết script
  • Commit nhỏ, mô tả rõ — người đọc lại là mình sáu tháng sau
  • Backup trước khi sửa thứ đang chạy
  • Đọc log trước khi đoán mò

Bỏ

  • Thêm thư viện cho một hàm mười dòng
  • Sửa trực tiếp trên server rồi quên đồng bộ lại repo
  • Tối ưu sớm thứ chưa ai dùng
  • Đặt tên biến kiểu tmp2_final_v3
  • Deploy lúc 11 giờ đêm thứ sáu

Code chạy được mà không hiểu vì sao chạy thì cũng là code sắp hỏng. Chỉ là chưa tới lúc thôi.
